# Settings Page Redesign — Floating Closable Sidebar

## Context (from exploration)
- Settings UI is **React 19 + Tailwind 4** (not Svelte) in a **separate Tauri window** (label `settings`, `src-tauri/tauri.conf.json`). Window show/hide/close semantics in Rust must not change.
- Today: `src/routes-react/SettingsPage.tsx` renders a **header** with `src/components/settings/SettingsTopBar.tsx` (centered icon-over-label tab strip) + scrolling content with 12 tab components in `src/routes/settings/tabs/`.
- Design system: tokens in `src/resources/styles/style.css`, enforced by `pnpm check:design` (`scripts/check-design.mjs`, rules in `.agents/skills/design-language/SKILL.md`). Icons: in-house `Icon` set. No sidebar component exists yet; `TabGroup` has a `sidebar` variant but we'll build a dedicated `SettingsSidebar` for full control (logo row, grouped nav, footer).

## Design (inspired by the image)
- **Floating sidebar**: a rounded panel (`--radius-popup`, `--shadow-launcher-popup`, `--bg-secondary`) anchored to the left edge with margin/gap from the window edge, floating over `--bg-primary`. Structure like the image:
  1. Top row: app logo/name + close (X) IconButton.
  2. Nav items: icon + label rows, active item gets `--bg-selected` pill; hover `--bg-hover`; grouped (General / Extensions & Browsers / Applications / etc. — group headers in `--text-tertiary` label style).
  3. Footer: pinned "About" + version row (equivalent of the image's user card zone); dev-build Badge lives here.
- **Close/open behavior** (floating panel + toggle): close button collapses the sidebar with a slide animation (`--dur-travel`, `--ease-travel` out / `--ease-recede` back). When closed, a small floating round reopen handle (IconButton) stays at the top-left; content area expands to full width. Escape closes the sidebar only if the escape-behavior setting says hide window — otherwise Escape keeps its existing window-hide semantics (do not break `updateEscapeBehavior`).
- **Content area redesign (full)**:
  - Per-tab page header like the image: large icon tile + page title (e.g. "General"), thin `--separator` rule below, optional subtitle.
  - Card-based sections: `SettingsSection`/`SettingsRow` restyled inside `--bg-secondary` cards with `--radius-md`; spacing per design skill settings density (`--space-5`/`--space-6`).
  - Keep the 12 existing tabs and all their logic; only presentation changes. Extensions tab keeps its full-bleed master/detail layout, adapted to the new shell.
